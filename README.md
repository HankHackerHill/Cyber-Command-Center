# RedOps Command Center

State-of-the-art command center application for authorized, contracted red team
and penetration testing engagements — OSINT through signed client report.

- **Dual-mode execution:** fully manual, fully autonomous passive AI, or hybrid
  with human-in-the-loop approval gates
- **Cryptographic scope enforcement:** signed Rules of Engagement, deny-by-default
  egress proxy, rate limiting, emergency killswitch
- **Provable compliance:** hash-chained append-only audit ledger, content-addressed
  evidence, client-ready reporting with CVSS v4 / CWE / SOC 2 / ISO 27001 / PCI-DSS mappings

Built per PTES, NIST SP 800-115, OWASP WSTG / API Top 10 / MASVS / LLM Top 10.
