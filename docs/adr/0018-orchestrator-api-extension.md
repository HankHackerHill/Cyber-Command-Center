# ADR-0018: Orchestrator API Extension — Engagement Lifecycle and Listing APIs
**Status:** Accepted. Reopens the Astra lane for apps/orchestrator and packages/contracts-py, adding: POST /engagements (create engagement in INIT_SCOPING with an RoE manifest draft), PUT /engagements/{id}/roe (update the draft; INIT_SCOPING only), and read-only listings GET /engagements/{id}/tasks, /findings, /plans for the operator UI. Existing endpoints, guards, and invariants are law. Rationale: M10 exposed that engagement creation, RoE provisioning, and task/finding listing were never assigned to a module; the orchestrator is the state authority and natural owner.
