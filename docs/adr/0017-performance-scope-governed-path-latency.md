# ADR-0017: Performance Scope — Governed-Path Latency
**Status:** Accepted. Authorizes Sol 6.1 to optimize, within apps/orchestrator and apps/policy-svc only: (a) the audit-event append path — non-transition audit events may become asynchronous with durable delivery, provided appends remain exactly-once, the hash chain and append-only trigger are preserved, and state-transition appends stay synchronous and atomic with the transition (invariant 2); (b) policy evaluation — a per-manifest decision cache keyed by manifest hash and request attributes, invalidated on manifest hash change, never bypassing deny-by-default, where a cached allow is provably identical to fresh evaluation; (c) accounting settlement batching that does not weaken the worker cap or breaker counting. Guards, signatures, invariants, and frozen paths are law.
**Gate clarification:** the M4 "<15 ms p99 proxy overhead" gate measures proxy-internal processing (phase-profiled ~0.65 ms median — passing). New explicit gate: end-to-end governed-path p99 median <50 ms across warmup plus 3 measured runs, for both plain HTTP and intercepted HTTPS.
**Rationale:** the MS1 capstone passed functionally; the latency failure is pipeline waits in policy/accounting/evidence/audit, not proxy forwarding. The original gate conflated proxy overhead with full-pipeline latency.
