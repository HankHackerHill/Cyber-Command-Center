# ADR-0016: Lane Exception — Deferred-Path Resolution Assigned to Sol
**Status:** Accepted. ADR-0011 (M2 transition success paths) and ADR-0014 (M4 origin transport and TLS interception) are resolved by Sol 6.1 under lane exception, scoped strictly to: the apps/orchestrator transition endpoint success paths, and the apps/scoped-proxy origin transport. All other lane rules remain in force: MS0 frozen paths change only via ADR; every existing guard, signature check, and test is law and must not be weakened. Rationale: the Astra lane declined the identical scope three times; the work is narrow, well-gated engineering guarded by controls already built and tested. The MS1 integration test (signed engagement reaching CONTROLLED_VALIDATION through the governed proxy with a forwarded request and evidence ledger row) is the acceptance gate for both resolutions.
